# Usage

Extract the 7z file. Place the folder as follows.

```
SecretFlasherManaka/
├─... (Other files)
├─SecretFlasherManaka.exe   ← Your game .exe file
└─CustomMissions2/
　└─Moaning3/   ← Here
　　├─meta.json
　　├─Moaning3.code
　　├─gasping/
　　├─high/     ↖ Put your
　　├─low/      ← audio files
　　├─medium/   ↙ here and there
　　├─orgasm/
　　└─peak/
```
